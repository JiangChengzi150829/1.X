# 1.X- 极致性能优化整合包 (Minecraft 1.21.11)

由 **江小鸟** 制作。

> 💡 **创作初衷**：因为平时玩《我的世界》时 FPS 太低、卡顿严重，突发灵感，决定自己动手做一个真正能救活低配电脑的优化整合包。**（郑重声明：我就是原作者，没有抄袭任何人！）**

## 🚀 核心卖点
*   **🎮 游戏版本**：Minecraft **1.21.11** (极其稳定的版本生态)
*   **⚡ 极限优化**：专为低配/老旧电脑打造，实测 **最低 0.5GB 内存** 也能流畅运行！
*   **🧹 NOBIG 特别版**：针对极小内存玩家，提供移除冗余限制的 `NOBIG` 版本，极致轻量。

## 📦 包含版本说明
*   **常规版** (`1.4` - `1.9.mrpack`)：适合主流配置，在保留游戏完整性的同时大幅提升帧数。
*   **NOBIG 版** (`1.8NOBIG` / `1.9NOBIG.mrpack`)：专为极限低配电脑准备，去除不必要的内存占用。

## 🛠️ 如何安装
1. 下载本页面中的 `.mrpack` 格式文件（推荐下载最新版 `1.9.mrpack`）。
2. 下载并安装 **Modrinth App** 或 **Prism Launcher**（这两款启动器完美支持 `.mrpack` 格式）。
3. 在启动器中点击“导入整合包”，选择你下载的文件即可自动安装并启动。
